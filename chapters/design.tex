This chapter details the architecture and algorithmic design of the proposed adaptive actuation system.

\section{System Architecture}
The system utilizes a multi-layered software and hardware stack designed to bridge high-frequency physical telemetry with a dynamic optimization engine. At the hardware layer, a modified PRO X2 Superstrike mouse streams continuous 120-level analog depth values at 1\,kHz. This bypasses typical firmware constraints that generally limit reporting to mere 4-bit precision at 65\,Hz and block reading after haptic events. The hardware communicates with the host operating system via GXT-Devio, an OS-level bridge that interfaces high-level prototyping environments (TypeScript/JavaScript) with production-grade HIDPP protocols. Sitting above this is Nightfall, a background sensor service that orchestrates and synchronizes the analog telemetry with other biometrics and OS events. Finally, GSense serves as the graphical orchestration client, providing the user dashboard and managing the downstream machine learning pipelines.

\section{Data Collection and Labeling}
Raw analog signals are inherently noisy. Before labeling, the depth telemetry is processed using Modified Akima (MAKIMA) interpolation. MAKIMA was specifically selected because it preserves signal monotonicity and prevents the severe overshoots characteristic of standard cubic splines. 

To alleviate the bottleneck of manual annotation, the system employs an automated mathematical labeling pipeline to bootstrap the data:
\begin{itemize}
    \item \textbf{Make Intention:} Detected at the first non-zero analog depth value marking the start of a downward press.
    \item \textbf{Break Intention:} Detected at the exact frame where the depth speed reverses (where local velocity crosses zero), indicating the start of a release.
\end{itemize}

While this algorithmic bootstrapping rapidly processes the bulk telemetry, training a high-fidelity machine learning model demands human-verified ground truth. Consequently, a curated subset of these sessions underwent rigorous manual annotation. The human labeling mindset focused strictly on physical, biomechanical intent---visually distinguishing and discarding involuntary micro-tremors and resting-weight drift, while preserving genuine, deliberate presses regardless of whether they resulted in a successful in-game action.

\section{Click-Intent Sequence Modeling}
To understand user intent, the system models the data as a supervised time-series segmentation problem, mapped down to a per-frame classification task. The core feature engineering relies heavily on extracting analytical "distant context probes" that provide models with past and future temporal context, combined with instantaneous features like analog speed, digital signals, and distance to dynamic thresholds.

The primary algorithm used for inference is a Random Forest (RF) classifier. More advanced architectures, such as Gradient Boosted Trees (GBT) accommodating custom loss functions, and Fully Dilated Convolutional Networks (FDCN) for direct raw sequence temporal modeling, operate within the same structural framework.

\section{Parameter Optimization}
Once intent boundaries are parameterized, the system tests potential hardware settings without physically altering the peripheral. The engine simulates the analog mouse click Finite State Machine (FSM) frame-by-frame, testing its actuation behavior both with and without Rapid Trigger logic enabled.

The optimizer relies on the Covariance Matrix Adaptation Evolution Strategy (CMA-ES) to explore the parameter space. Candidates are evaluated through a multi-objective hand-crafted loss function that balances Recall (not missing clicks), Precision (avoiding accidental misclicks), and Latency (an early prediction penalty aimed at minimizing the temporal distance between simulated triggers and true user intent).
