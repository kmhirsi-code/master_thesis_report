\begin{abstract}
Analog peripherals with continuous depth-sensing hardware offer sub-millimetre
actuation precision, yet their firmware often relies on static thresholds that
ignore per-user biomechanical variance and degradation under neuromotor fatigue.
This thesis addresses that gap by designing an end-to-end click-sensitivity
recommendation pipeline for Haptic Inductive Trigger System (HITS) devices, evaluated on a set of 26 participants.

The system makes three contributions.
(1)~A supervised labeling workflow that bootstraps frame-level annotations from
algorithmic criteria and iteratively improves them through model-assisted
refinement, substantially reducing the manual annotation burden while
preserving the boundary precision needed for downstream training.
(2)~A four-class temporal intent-detection model supporting three
architectures: a Random Forest and a Gradient Boosted Trees variant operating
on hand-crafted sliding-window features, and a dilated residual FCN operating
directly on raw telemetry with a large learned receptive field. The Random Forest
achieves the best deployment performance (F1~0.970 on the left channel), and
a probe ablation shows that raw local context around each frame is a far
stronger predictor than explicit kinematic derivative features.
(3)~A firmware-faithful threshold optimizer that exhaustively evaluates the
discrete (AP, RT) grid via a Rapid Trigger FSM simulator, replacing manual
threshold tuning with a data-driven recommendation. Across the annotated
corpus, the optimizer consistently reduces make latency and increases the
true-positive detection rate relative to the factory default, with the
improvement holding across every session evaluated.
\end{abstract}
